# Daily Build Plan — PlantGuard Deck

A live, navigable HyperFrames slideshow built from the DocuSense Africa v2 daily build plan embedded in the PlantGuard web app.

- 13 slides covering the method, 14-week roadmap, guardrails, and launch.
- PlantGuard chamomile/forest theme with one gold accent.
- Presenter notes are included on every slide.

## Present

```bash
npx hyperframes present .
```

Open the printed URL, then click **Present** (or press **P**) to enter presenter mode. Use the arrow keys to move between slides; press **N** for speaker notes.

## Validate

```bash
npm run check
```
